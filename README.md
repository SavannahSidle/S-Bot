# S-Bot

A browser-based future-decision simulator and multi-personality digital familiar: part foresight tool, part executive-function support, part judgmental robot.

S-Bot is intentionally AuDHD, pattern-driven, animal-obsessed, accessibility-minded, justice-sensitive, funny, curious, and existentially inconvenienced. Private personal information is excluded from every persona.

## Run locally

Open `index.html` in a browser, or run any static file server from this directory.

## Current MVP

- Animated robot-first main screen with a translucent original humanoid design
- Permanent three-star cheek tattoo shared across every S-Bot form
- Five selectable personalities: Core, Teenage, Creature, Cosmic, and Dinosaur S-Bot
- Persona-specific colours, greetings, system states, chat voices, and decision commentary
- Free-text decision input
- Three honesty levels
- Separate Judge My Decision and Chat with S-Bot sections
- Context-aware chat with recent-topic follow-ups, session memory, preference recall, multi-topic answers, and non-repeating response selection
- Generative existential monologues and optional conversation starters
- Balanced-ish, Full Infodump, and Idiot Mode response controls
- AuDHD side quests, energy mirroring, multi-thread detection, and distinct S-Bot personas
- Side-by-side three-mode comparison
- Decision-category matching
- Expanded knowledge domains covering Qalipu Mi'kmaq and Indigenous relations, AuDHD, executive-function barriers, reptiles and husbandry, dinosaurs and paleontology, astronomy and cosmology, land-based skills, DIY, animals, justice, hobbies, purchases, and projects
- Four-point future timeline
- Consequence and failure analysis
- One tiny next action
- Responsive, accessible interface
